# 이 발표 앱(슬레이트)에 대한 사실 / 关于这个发表 App 的事实

질문에 답할 때 참고하는 자료입니다. 아바타 자신이 어떻게 만들어졌는지 물으면 이 내용을 근거로 답합니다.

- 이름: AI Avatar Presenter "슬레이트". 곽우화가 프롬프트 엔지니어링 수업 중간 과제로, 교수님의 "Claude Code 활용" 튜토리얼(PPT 를 읽어 주고 LLM 으로 질의응답하는 강아지 캐릭터 프로그램)을 응용해 Claude Code 와 함께 만들었다.
- 기획: 튜토리얼처럼 먼저 사용 장면을 한 줄로 적고("학생이 포트폴리오 사이트를 띄워 두면 캐릭터가 각색해서 소개하고 질문에 답한다"), wayfinder 방식으로 질문과 답을 기획 문서 6개(docs/plan)로 정리한 뒤 문서대로 구현했다.
- 캐릭터: 영화 촬영장의 클래퍼보드 모양. SVG 로 직접 그렸고, 마우스를 따라 걸어오며, 말할 때 위쪽 클래퍼가 입처럼 열리고 닫힌다. 발표 중 마우스가 멈추면 지금 설명하는 구역 옆으로 걸어간다. 사이트 배색(검정·흰색·파랑·노랑)을 썼다.
- 사이트 읽기: 로컬 Node.js 서버가 포트폴리오 사이트를 같은 주소로 중계(프록시)해서, 앱이 사이트의 탭을 직접 누르고 내용을 읽는다. 4개 탭에서 29개 구역을 읽고, 영화·스틸 사진 상세 설명은 카드를 하나씩 열어 읽는다. 과제 문서(마크다운, 자막)도 함께 읽는다. 사이트가 바뀌면 바뀐 내용을 그대로 읽는다.
- 대본: Claude API(모델 claude-opus-5-5)에 사이트 내용과 과제 문서를 주고, 그대로 낭독하지 말고 사람이 소개하듯 재구성하라는 원칙으로 약 11분 분량 대본을 만든다. Structured Outputs 로 "어느 구역에서 무엇을 말할지"를 JSON 으로 받아서, 말에 맞춰 화면이 자동으로 탭을 바꾸고 스크롤하고 노란 테두리로 강조한다. 만든 대본은 저장해 두고 다시 쓴다.
- 질의응답: Chrome 의 음성 인식(Web Speech API, 한국어)으로 질문을 듣고, Claude 에 스트리밍으로 물어서 문장이 완성되는 대로 바로 읽는다. 사이트와 문서는 프롬프트 캐시(1시간)에 넣어 두 번째 질문부터 빠르고 싸다. 답변과 관련된 구역으로 화면도 이동한다. 최근 4개 질문을 기억한다. 질문한 언어로 답한다.
- 음성: 브라우저 내장 음성 합성(macOS 의 Yuna 목소리), 문장 단위로 읽는다.
- 앱 형태: Chrome 을 주소창 없는 앱 모드 창으로 띄운다. Electron 은 음성 인식이 동작하지 않아서 쓰지 않았다. Mac 은 .app, Windows 는 .bat 을 더블클릭하면 실행된다. API 키는 이 컴퓨터의 .env 파일에만 있고 브라우저로 보내지 않는다.
- 30초 녹화본: 헤드리스 Chrome 화면을 CDP screencast 로 받아 같은 음성 파일과 합쳐서 자동으로 만들었다.
