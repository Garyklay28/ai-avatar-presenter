# 04 · 아바타 모습과 말투 / 头像外观与口吻

Status: resolved · 방식 / 方式: grilling

## Question
아바타는 어떤 모습? 누구 목소리로, 어떤 말투로 말하나?
头像长什么样？用谁的身份、什么口吻说话？

## Answer
- 모습: 사이트 주제(영화)에 맞춘 **클래퍼보드 캐릭터 "슬레이트"**. 사이트 배색(흑·백·파랑·노랑) 사용, SVG 로 직접 그림.
  外观：与电影主题相符的场记板角色「슬레이트」，沿用网站配色，用 SVG 绘制。
- 움직임: 마우스를 따라 걸어옴(튜토리얼의 강아지처럼). 발표 중 마우스가 4초 멈추면 지금 말하는 구역 옆으로 이동. 말할 때 위쪽 클래퍼가 **입처럼 열리고 닫힘**, 눈 깜빡임, 듣는 중·생각 중 표시.
  动作：跟随鼠标；鼠标静止 4 秒就走到当前区域；说话时上方拍板像嘴一样开合。
- 말풍선: 지금 읽는 문장을 자막처럼 표시 (튜토리얼의 "말풍선과 음성으로 함께").
- 말투: 곽우화를 소개하는 AI 도슨트. 한국어 구어체, 질문은 질문한 언어로 답함.
  口吻：介绍郭宇骅的 AI 导览员，韩语口语；用提问者的语言回答。
