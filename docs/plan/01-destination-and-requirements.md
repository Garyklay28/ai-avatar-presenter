# 01 · 목적지와 요구사항 / 目的地与需求

Status: resolved · 방식 / 方式: grilling

## Question
기획이 끝났다는 건 무엇이 나온 상태인가? 누가, 어떤 장면에서 쓰는가? 꼭 지켜야 할 조건은?
规划完成意味着得到什么？谁、在什么场景用？必须遵守的条件？

## Answer
- **사용 장면 / 使用场景**: 학생(곽우화)이 중간 발표에서 포트폴리오 사이트를 띄워 두면, 클래퍼보드 캐릭터가 마우스를 따라다니며 사이트 내용을 **각색해서** 소개하고, 끝나면 현장 학생들의 질문을 **듣고** 사이트 내용을 근거로 답한다.
  学生在期中发表时打开作品集网站，场记板角色跟着鼠标，把网站内容改编后介绍；之后听取现场提问并依据网站内容回答。
- **꼭 지킬 조건 / 硬性条件**
  1. Windows 와 Mac 모두 동작 / Windows 与 Mac 都能运行
  2. 홈페이지 글자를 그대로 낭독하지 않는다 (재구성한 대화체) / 不照读网页文字
  3. 실시간 질의응답 (음성 입력 + 음성 답변) / 实时语音问答
  4. 발표 5분 이상 (질의응답 포함 10분) / 发表 5 分钟以上
  5. 제출물 ①사용 가이드 ②README ③30초 녹화 ④GitHub 새 레포
- **끝난 상태 / 完成状态**: 더블클릭으로 앱 창이 열리고, ▶ 한 번으로 6분 발표, 🎤 로 질문 답변이 되는 상태 + 제출물 4가지.
- **새로 만드는가 / 新建还是扩展**: 포트폴리오 사이트(React + Supabase)는 건드리지 않고, 사이트를 "읽는" 별도 앱을 새로 만든다. 사이트가 바뀌면 앱이 바뀐 내용을 그대로 읽는다.
  不改网站本身，另做一个"读"网站的 App；网站更新后 App 自动读到新内容。
