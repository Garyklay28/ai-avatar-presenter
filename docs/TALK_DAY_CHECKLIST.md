## 3. 발표 중 / 发表中

| 상황 / 情况 | 누를 것 / 按什么 |
|---|---|
| 시작 / 开始 | **▶** 또는 `P` (답변 캐시도 이때 데움 / 同时预热回答缓存) |
| 손 든 학생 / 有人举手 | `Space` → 학생이 노트북 앞에서 질문 → 답변 → **5초 뒤 자동으로 이어감** / 按空格 → 学生对着笔记本提问 → 回答 → **5 秒后自动继续** |
| 카운트다운 중 / 倒计时中 | `Space` 추가 질문 · `P` 바로 이어감 · `Esc` 멈춘 채로 / 空格追问 · P 立即继续 · Esc 保持暂停 |
| 중국어·영어 질문 / 中文、英文提问 | 먼저 `L` → 中 (한 번 더 → EN), 질문이 끝나면 자동으로 「한」 / 先按 L 切到「中」（再按一次 → EN），问完自动回到「한」 |
| 답변이 엇나감 / 回答跑偏 | 답변 중 `Space` = 끊고 다시 듣기 · `Esc` = 멈춤 / 回答中空格 = 打断重听 · Esc = 停止 |
| 시끄러움·인식 엉망 / 太吵、识别差 | `Enter` → ⌨ 로 입력 (보낼 때 발표가 멈춤) / 回车打字提问（发送时才暂停） |
| 「잘 듣지 못했어요」 | 언어 버튼 확인 후 다시 `Space` / 确认语言按钮后再按空格 |

## 4. 문제가 생기면 / 出问题时

| 증상 / 现象 | 할 일 / 怎么办 |
|---|---|
| 소리가 안 남 / 没声音 | 사운드 출력 장치 확인 → 🔊 목소리 듣기 / 检查输出设备 → 试听 |
| 🎤 빨개지는데 글자가 안 나옴 / 变红但没字 | 사운드 **입력** 장치 확인 → 앱 창에서 ⌘Q 로 완전히 끄고 다시 실행 → 급하면 ⌨ / 检查**输入**设备 → 在 App 窗口按 ⌘Q 完全退出再打开 → 急用就打字 |
| 인터넷 끊김 / 断网 | 발표는 그대로 진행(확정 대본). 질의응답은 핫스팟 연결 후 / 发表照常进行，问答连热点后再做 |
| 「질문 처리 실패」 / 回答失败 | 네트워크·잔액 확인, ⌨ 로 다시. 안 되면 본인이 직접 답 / 检查网络和余额，用 ⌨ 再问；不行就本人回答 |
| 앱이 멈춤 / App 卡住 | ⌘Q → 다시 실행 → ☰ → 대본 목록에서 멈춘 문단을 눌러 거기서부터 / ⌘Q 后重开 → 在讲稿列表点暂停的那段，从那里继续 |
